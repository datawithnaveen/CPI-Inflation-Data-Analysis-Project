# India CPI Inflation Data Analysis Using Microsoft Excel

This project focuses on analyzing India's Consumer Price Index (CPI) data using Microsoft Excel to understand inflation patterns, price fluctuations, and the factors influencing consumer prices over time. The primary objective was to transform complex economic data into meaningful insights through structured analysis and visualization.

The analysis covers category-wise CPI contributions, year-wise and month-on-month inflation trends, and price movements across food categories. It also examines inflation patterns during the COVID-19 pandemic and explores imported oil price fluctuations between 2021 and 2023.

Additionally, correlation analysis was performed to investigate relationships between oil prices and different CPI categories, helping identify potential connections between energy costs and inflation trends.

**Tools and Techniques Used:**

- Microsoft Excel
- Pivot Tables and Charts
- XLOOKUP and INDEX-MATCH
- IF and COUNTIFS Functions
- Correlation Analysis
- Data Cleaning and Visualization

Completed over 20 days, this project strengthened my technical Excel skills, analytical thinking, problem-solving abilities, and understanding of real-world economic datasets.

More importantly, it helped me develop a structured approach to investigating economic trends, interpreting data, and communicating analytical findings effectively.

This project demonstrates how Excel-based data analysis can make complex inflation data easier to understand and support informed, data-driven economic discussions.
